# 🚗 GODZ Vehicle Branding Guidelines

Para manter a imersão e evitar problemas de copyright, todos os veículos neste servidor devem seguir as diretrizes de "Debadging" e "Lore-Friendly".

## 1. Regras Gerais
- **NENHUMA** marca real deve estar visível (BMW, Mercedes, Ferrari, etc.).
- Substitua logos reais por:
  - Logos do GTA V (Ubermacht, Benefactor, Grotti).
  - Logo **GODZ** (para veículos exclusivos).
- Placas devem seguir o padrão Mercosul ou GTA V Lore.

## 2. Estrutura de Pastas
Organize os veículos dentro de `[godz_assets]/[vehicles]` por categoria:
- `[godz_cars_sport]`
- `[godz_cars_suv]`
- `[godz_bikes]`
- `[godz_emergency]`

## 3. Como fazer o Debadging (Conceitual)
1. Abra o arquivo `.ytd` (textura) do veículo no OpenIV.
2. Localize texturas com logos (ex: `steering_wheel`, `badge_f`, `badge_r`).
3. Exporte a textura e edite no Photoshop/GIMP.
4. Substitua o logo real pelo logo GODZ ou remova-o.
5. Importe de volta e salve.

## 4. Handling
- Otimize o `handling.meta` para dirigibilidade realista, não "arcade".
- Evite velocidades irreais (>300km/h para carros comuns).
