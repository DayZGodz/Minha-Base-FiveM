# 👑 Família God - Super Base Unified (2026)

## Sobre
Base exclusiva focada em performance e RP de alta qualidade, resultado da fusão das bases Unity Clean, Zirix v2 e Bahamas (Hensa).

## Destaques Técnicos

### Rebranding Total
Migração completa de `vrp_` para `godz_` em scripts e banco de dados, garantindo uma identidade única e código limpo.

### Core Estabilizado
Correção de race conditions no inventário e inicialização protegida de itens básicos, eliminando bugs de perda de itens ou duplicação.

### Infraestrutura
Uso de `godz_updater.py` para manter artefatos sempre na versão RECOMMENDED, garantindo estabilidade e segurança contra exploits.

### IA Bridge
Integração com sistema de auditoria econômica e suporte via Discord, permitindo monitoramento em tempo real da economia do servidor.

### Arquitetura de Pastas
Separação profissional para facilitar a manutenção e CI/CD:
- **artifacts/** (Engine): Contém os binários do servidor.
- **server/** (Data): Contém recursos, configurações e banco de dados.
